# Security policy

SigmaProof is pre-implementation. No version is currently supported for production or regulated use.

Use GitHub private vulnerability reporting from this repository's Security tab when available. If unavailable, contact a SigmaUno organization administrator through their published private contact channel before sharing sensitive details. Do not post exploitable vulnerabilities, keys, private proofs, or customer documents in public issues.

Include affected revision, reproduction with synthetic data, expected and observed behavior, impact, and any proposed mitigation. Maintainers will assess reports without a guaranteed response time. A formal supported-version and coordinated-disclosure policy is required before the first production release.
