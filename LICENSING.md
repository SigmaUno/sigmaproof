# Licensing status

No open-source license has been selected yet. The project intends to publish an open evidence protocol and implementation, but that intention does not grant a license. SigmaUno's project owner must select licensing terms before public launch and external contributions intended for redistribution.

Apache-2.0 is the proposed option for its permissive terms and explicit patent grant; it has not been adopted. No LICENSE file is included until that decision is made.
