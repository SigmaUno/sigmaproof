# SEP-8: Evidence Renewal

Status: draft · Editor: SigmaUno project maintainers

## Purpose

Append new protection to preserved historical evidence without replacing it.

## Design requirements

Bind prior evidence bytes/digest and identity, renewal reason, new algorithms, fresh object digests when needed, signatures, timestamps, anchors, and applicable policy. Preserve all previous revisions and trust evidence. Renew while earlier binding and authentication assumptions still hold.

## Decisions required before implementation stability

Define linkage, exact covered bytes, evidence age semantics, migration and failure handling, and reproducible renewal vectors. Hashing a compromised old digest with a stronger algorithm cannot restore its original object binding.

## Acceptance

Publish precise byte-level rules, independent positive and negative test vectors, compatibility behavior, and security considerations. Review before marking this draft stable.
