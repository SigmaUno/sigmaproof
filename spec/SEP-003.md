# SEP-3: Metadata Commitments

Status: draft · Editor: SigmaUno project maintainers

## Purpose

Commit a clearly defined metadata snapshot without making it public.

## Design requirements

Define the exact field selection, types, canonicalization, and metadata digest. Preserve the snapshot privately when full verification is required. An absent snapshot means its digest cannot be recomputed. Partial disclosure requires a separate design and is not supplied by a whole-object digest.

## Decisions required before implementation stability

Resolve number handling, Unicode, null versus absent values, versioning, and privacy requirements. Hashing noncanonical ordinary JSON is not interoperable.

## Acceptance

Publish precise byte-level rules, independent positive and negative test vectors, compatibility behavior, and security considerations. Review before marking this draft stable.
